# Guides

Each guide takes one task from start to finish: the steps in the Web UI, then the same thing from a terminal.

- [Make images](images.md): pictures from a prompt.
- [Make video](video.md): clips with sound from a prompt or a starting image, and longer clips by extending.
- [Make music](music.md): songs and instrumentals.
- [Make speech and sound](speech-and-sound.md): text read aloud, ambience and sound effects.
- [Get better results](better-results.md): clearer prompts, the enhancer, upscaling, variations, presets, LoRAs and references.
- [Keep work separate with projects](../concepts/projects.md): pick a project before you generate, so new work doesn't mix with earlier files.
- [Run batches from prompt files](batches.md): many prompts in one run.
- [Download, delete and convert models](models.md): free disk space and use your own fine-tunes.
